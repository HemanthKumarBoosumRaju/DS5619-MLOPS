# Week 8 - Drift and Observability Monitoring

## Overview

This lab implements drift monitoring for a vehicle detection system.

The confidence scores produced by the detector are used as the monitored feature. Two camera conditions are compared:

- `camera_A_daylight` - reference distribution
- `camera_B_lowlight` - live distribution

The Population Stability Index (PSI) is used to measure the difference between the two distributions.

## Implementation

Four functions were implemented in `src/drift_monitor.py`.

### `extract_confidence_scores()`

Runs the detector on every `.jpg` image and collects the confidence score from every detection.

### `compute_psi()`

Divides the confidence scores into 10 bins and compares the reference and live distributions using PSI.

### `classify_drift()`

Classifies the PSI value using:

```text
PSI < 0.10           -> none
0.10 <= PSI < 0.25  -> moderate
PSI >= 0.25         -> significant
```

### `summarize_scores()`

Calculates:

- Count
- Mean
- Standard deviation
- Minimum
- Maximum

It also handles a single score by returning `std = 0.0`.

## Files and Their Purpose

### `src/drift_monitor.py`

Contains the main implementation of the lab.

It extracts confidence scores, calculates PSI, classifies drift, and calculates summary statistics.

### `src/mock_detector.py`

Provided detector used by the lab.

It simulates the vehicle detector and produces detections with confidence scores. This file was not modified.

### `src/run_pipeline.py`

The complete pipeline driver.

It:

1. Extracts scores from both cameras.
2. Summarizes the scores.
3. Calculates PSI.
4. Classifies the drift.
5. Writes `drift_report.json`.

This file was not modified.

### `generate_for_student.py`

Generates the personalized synthetic camera images using the student ID.

The generated data is deterministic for the selected student ID.

### `data/fixtures/camera_A_daylight/`

Contains the generated daylight camera images.

This is treated as the **reference distribution**.

### `data/fixtures/camera_B_lowlight/`

Contains the generated low-light camera images.

This is treated as the **live distribution** being monitored.

### `drift_report.json`

Generated by:

```bash
python src/run_pipeline.py
```

Contains the confidence-score summaries, PSI value, and drift level.

For this run, it reported a PSI of `0.1303` and a **moderate** drift level.

### `tests/`

Contains the self-check tests for the lab.

The tests check confidence-score extraction, deterministic results, PSI calculation, drift thresholds, summary statistics, and the complete pipeline.

### `NOTES.md`

Contains the student-specific information and observations required for submission.

It records:

```text
Student ID: 142602003
Seed: 3455375467
```

It also records the observed drift level and explains why the result is expected.

The notes state that:

- The PSI was `0.1303`.
- The drift level was `moderate`.
- The moderate drift is expected because the two cameras were deliberately generated with different visual conditions.
- If ground-truth labels become available, metrics such as precision, recall, F1-score, and mAP should also be monitored.
- Confidence-score monitoring alone can miss concept drift, where the correct output changes even though confidence scores remain similar.
